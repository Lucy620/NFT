In this stage, the system have achieved the following functions depending on ERC1155:
Mint multiple NFTs by uploading an image;
Display NFTs categorized by public and self-owned;
Display transaction history for each transaction;
Ownership and Ether Transaction on multiple NFTs.


If you would like to run the program, please follow the steps to input in terminal:

Start Ganache Server first by input "ganache-cli" , and there should be 10 test accounts provided.

Migrate the contracts by input "truffle migrate --reset"

Input "yarn start" to start the program in the localhost website.

When running the program in the browser, make sure you added the chrome extension "Metamask" which will help the program connect to test blocakchain and simulate transaction.

You will also set up a new network with RPC URL: http://127.0.0.1.8545 and Chain ID: 1337

You also need to import account in the above new network with the privacy key provided by Ganache in the terminal and make sure the account is active when running the program.
